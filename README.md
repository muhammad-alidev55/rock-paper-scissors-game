# **Rock Paper Scissor Game**

A simple and fun **Rock Paper Scissor Game** built using **HTML**, **CSS**, and **JavaScript**.  
In this game, the user plays against the computer, and the scores update automatically after each round.

# **Features:**

- User vs Computer gameplay
- Random computer choice generation
- Live score tracking
- Result message display
- Interactive UI with hover effects
- Simple and beginner-friendly project


## **Technologies Used**

- HTML5
- CSS3
- JavaScript (DOM Manipulation)

## **Game Rules:**

- Rock beats Scissor
- Scissor beats Paper
- Paper beats Rock

If both user and computer choose the same option, the match is a draw.

## **How to Run the Project**

1. Download or clone this repository

```bash
git clone https://github.com/your-username/rock-paper-scissor.git
```

2. Open the project folder

3. Run the `index.html` file in your browser
